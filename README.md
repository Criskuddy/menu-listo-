# MenúListo

Menús y catálogos digitales con código QR para negocios de Monterrey centro.

- Negocio: MenúListo, @menulisto en Instagram, Facebook y WhatsApp Business
- Paquetes: Inicial $500, Estándar $1,500 + $250/mes, Premium $3,000 + $500/mes
- Hosting: GitHub Pages (gratis), en este repositorio público

## Menús publicados

- Café Bruma (ejemplo): https://criskuddy.github.io/menu-listo-/cafe-bruma/
  - También en la raíz: https://criskuddy.github.io/menu-listo-/

Cada cliente tiene su propia carpeta, por ejemplo `cafe-bruma/`, `taqueria-el-faro/`, `estetica-luna/`. El QR apunta a esa dirección fija; si se actualiza el menú en esa misma carpeta, el QR sigue funcionando sin reimprimir.
